# 中科大《数学分析讲义》习题解答 (Unofficial Solutions)

本项目旨在为中国科学技术大学出版的《数学分析讲义》提供一份排版精良、解析详尽的非官方课后习题参考答案。

## 💡 编写初衷

中科大的这本《数学分析讲义》编写水平极高，是不可多得的优秀教材。然而，本书的一个遗憾是**没有附带课后习题解析**。

作为正在使用这本教材的学生，我们在完成老师布置的作业后，往往因为缺乏标准答案而无法获得及时的反馈，不知道自己的证明或计算是否严谨。在互联网上多方搜寻无果后，我决定自己动手，做那个“第一个吃螃蟹的人”，为这本书整理出一份完整的习题集。

## 🚀 项目特色

* **排版精良**：基于标准 LaTeX 出版物级别的排版，阅读体验极佳。
* **AI 辅助生成**：本项目拥抱前沿技术，题目提取与解答参考均由先进的 AI 模型（Gemini 3.1 Pro）辅助完成，极大地缩短了编写周期。
* **结构清晰**：严格按照原书的章节结构进行划分，方便对照查找。

## 🤝 参与贡献与纠错

由于解答部分主要由 AI 生成，尽管经过了检查，但数学的严谨性意味着难免可能存在纰漏或不够巧妙的证明。

非常欢迎大家：
1. 提交 **Issue** 探讨某道题的具体解法或指出错误。
2. 提交 **Pull Request** 为这本习题集提供更优雅的解答。
