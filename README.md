# 卢德馨《大学物理学（第二版）》习题解答

这是卢德馨《大学物理学（第二版）》的非官方习题解答与校勘项目。正文按原书章节和题号组织，目标是给出可以逐步核查的推导、单位检查和必要的物理解释，而不只列最终数值。

## 内容与校勘

每章开头保留原书书末的奇数题参考答案，便于快速对照；随后给出完整题目与详细解答。章首参考值只负责忠实记录原书，并不自动覆盖正文推导。

现稿已经针对以下方面做过多轮复核：

- 研究对象、参考系、正方向和理想化条件是否明确；
- 矢量方向、正负号和坐标约定是否前后一致；
- 单位、量纲和有效数字是否可复算；
- 复杂题的极限情况是否与物理直觉相符；
- 图像、函数关系和关键中间量是否解释充分；
- 原书书末答案与独立推导冲突时，是否在正文中明确说明；
- 最终 PDF 的公式、图表、代码和分页是否可读。

这是一份学习与复习资料，不是教材官方答案。若教材版本、课堂约定或题目数据不同，应优先核对实际题面。

## 编译

主文件：`大学物理学.tex`

推荐使用 XeLaTeX 与完整 TeX Live。中文使用 Fandol 字体集，西文使用 TeX Live 自带字体，因此仓库不打包本地字体目录。项目基于 BeautyBook，只保留当前封面和章节排版实际需要的少量图片与轻量矢量图。

编译 PDF、日志和本地构建缓存不作为源码提交；需要成品时请从当前源码重新编译。

## 使用与贡献

建议先独立完成题目，再用本项目核对模型、推导和结果。若发现题面转录、公式、物理解释或排版问题，欢迎提交 Issue 或 Pull Request；如能附上原书页码、题号和完整推导，会更便于复核。
